## Frequency note

The original example project used the `MHZ_868` / `MHZ_915` configuration names.
The actual RF settings used by this firmware are for **433 MHz**; the names in
the original workspace were legacy labels. The build configurations in this
repository are named `433MHz_Alarm` and `433MHz_Raw`.
